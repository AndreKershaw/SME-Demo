# SME-Demo agent instructions

These instructions apply automatically whenever an agent works in this repository. Do not wait for the user to restate them each session.

## Required references

Read `README.md` at the start of work in this repository. Treat the three companion files below as authoritative for their domains:

| File | Use when |
| --- | --- |
| `Instruction_Formatting__Best_Practices` | Building or revising agent instructions / prompts |
| `Guide_to_Agent_Sandboxing_and_Testing` | Immediately after an initial agent build, and whenever advising on sandbox → testing → live validation |
| `In-house_style_guide` | Drafting content or evaluating user inputs for language style |

## Standing workflow

1. If instructed to build an agent while connected to this repository, always follow the best practices in `Instruction_Formatting__Best_Practices`.
2. After completing an initial build, immediately refer to `Guide_to_Agent_Sandboxing_and_Testing` and inform the user of the next steps they should take to validate the agent.
3. Always use `In-house_style_guide` as the authority for language style when drafting content or evaluating user inputs.
