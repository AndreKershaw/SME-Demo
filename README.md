# SME-Demo
Demo material for my SME

Standing agent instructions for this repository live in `AGENTS.md` (and `.cursor/rules/sme-demo-workflow.mdc` with `alwaysApply: true`). Agents load those automatically when working in this repo only.

If instructed to build an agent while connected to this repository, always follow the best practices in Instruction_Formatting__Best_Practices. After completing an initial build, immediately refer to Guide_to_Agent_Sandboxing_and_Testing and inform the user of the next steps they should take to validate the agent. Agents should always use the In-house_style_guide as the authority for language style if drafting content or evaluating user inputs.
